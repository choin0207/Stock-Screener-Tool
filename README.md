# Stock Screener Tool — 台股每日篩選 + 盤中量能監控

以官方公開資料自動篩選台股（**涵蓋上市＋上櫃全部個股**），並在盤中每 10 分鐘監控成交量、爆量即時警示的**跨平台 PWA 網頁應用**——手機、平板、電腦瀏覽器都能開，還可「加入主畫面」當成 App 使用。

## 兩種使用模式

| | 🌐 雲端模式（推薦，免伺服器） | 💻 本機模式 |
|---|---|---|
| 怎麼開 | 手機/電腦直接開 GitHub Pages 網址 | 電腦跑 `python app.py`，同 Wi-Fi 手機開 `http://電腦IP:5000` |
| 資料更新 | GitHub Actions 自動排程（每日 15:30 篩選、盤中每 10 分鐘量能監控），結果 commit 回 repo | 內建 APScheduler 排程即時執行 |
| 需要自己的電腦開機 | ❌ 不用 | ✅ 要 |
| 手動觸發按鈕 | 無（可到 Actions 頁按 Run workflow） | 有「立即篩選/檢查量能」按鈕 |

前端會自動偵測模式：連得到後端 API 就顯示「即時模式」，否則以靜態 JSON 顯示「雲端模式」。

### 雲端模式部署步驟（一次設定，之後全自動）

1. 在 GitHub 建立新 repo（例如 `Stock-Screener-Tool`），把本資料夾**全部內容**推到 repo 根目錄（`.github/` 資料夾要一起）。
2. Repo → Settings → Pages → Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 **/docs** → Save。
3. Repo → Actions 頁面按下啟用 workflows。
4. 完成！網址為 `https://<你的帳號>.github.io/<repo名>/`，手機開啟後用瀏覽器選單「加入主畫面」即可像 App 一樣使用。

註：GitHub Actions 排程為盡力執行，尖峰時段可能延遲幾分鐘；瀏覽器通知需開著頁面才會跳出（頁面每分鐘輪詢警示檔）。iPhone 的通知需先「加入主畫面」後從主畫面開啟。

## 篩選條件（每日盤後執行）

| # | 條件 | 實作方式 |
|---|------|----------|
| 1 | 三大法人中的外資與投信，與前一日相比大量購入 | 外資、投信當日皆為買超，且兩者合計買超 ≥ 前一日合計買超 × 2（`inst_surge_ratio` 可調） |
| 2 | 買賣超大於前日 3 倍以上 | 三大法人合計買賣超 > 前一日買賣超 × 3（前一日需為買超，`net_buy_ratio` 可調） |
| 3 | 持股轉讓沒有「一般交易」超過 100 張 | 近 30 日內部人（董監事/經理人/大股東）持股轉讓申報中，「一般交易」方式合計 ≤ 100 張 |
| 4 | 合約負債大於資本額的一半 | 最新一季資產負債表：合約負債（流動）> 股本合計 × 0.5（`contract_liability_capital_ratio` 可調） |
| 5 | 獲利能力大於 1.5 | 最新一季基本每股盈餘 EPS > 1.5 元（`profitability_metric` / `profitability_threshold` 可調） |

### 分級列表

結果不只顯示全過的股票，而是把通過條件①②（法人動能門檻）的候選股**全部列出**，
依符合程度分成三級供選擇，並以標章顯示每檔的 ③④⑤ 通過狀況：

1. 🏆 **符合全部條件**（5/5）
2. 🟡 **法人動能＋合約負債達標的部分符合股**
3. 🔵 **全市場合約負債達標股** — 不論法人是否進場，只要「合約負債＞資本額一半」
   就列出（需先執行每週的 Financial Scan 建立全市場財報資料庫）
4. ⚪ 其他法人動能股（④未達標，僅供參考）

每檔股票會列出：**收盤價、漲跌、外資與投信買進/賣出/買賣超（含前一日對照）、
主力進出買賣超、集保大戶（1000 張以上）持股比率與週變動、近 30 日一般交易持股轉讓張數、
合約負債、資本額、EPS**。

## 盤中量能監控（每 10 分鐘）

* 監控對象：每日篩選結果 + `monitor_extra_symbols` 中額外指定的個股。
* 每 10 分鐘記錄當日累積成交量，計算「最近一段成交量」與「當日先前平均段量」。
* 當最近一段量 **> 平均段量 × 10 倍**（`volume_spike_ratio` 可調）時，
  在網頁上顯示警示並發出**瀏覽器通知**（需按「啟用瀏覽器通知」授權）。
* 注意：證交所即時 API 提供總成交量、不區分內外盤買賣量，故以爆量作為大量買盤的近似指標，
  警示會附上現價與漲跌供判讀。

## 資料來源（皆為官方公開資料）

| 資料 | 來源 |
|------|------|
| 收盤行情 | 證交所 OpenAPI `STOCK_DAY_ALL`（上市）＋櫃買中心 OpenAPI `tpex_mainboard_quotes`（上櫃） |
| 三大法人買賣超 | 證交所 `T86`（上市）＋櫃買中心 `insti/dailyTrade`（上櫃） |
| 集保大戶（>1000 張） | 集保結算所開放資料「股權分散表」(`opendata.tdcc.com.tw` id=1-5)，第 15 級＝持股 1,000,001 股以上；**週資料**，需累積兩週後才能顯示週變動 |
| 內部人持股轉讓 | 證交所 OpenAPI `t187ap12_L`（上市）＋MOPS 開放資料 `t187ap12_O.csv`（上櫃） |
| 合約負債 / 股本 / EPS | 公開資訊觀測站 (MOPS) 個別公司資產負債表 `ajax_t164sb03`、綜合損益表 `ajax_t164sb04`（僅對通過前段篩選的個股查詢，並加延遲避免被封鎖） |
| 主力進出 | 官方無彙總開放資料；輔以富邦證券分點頁，失敗時以「三大法人合計買賣超」替代並於欄位提示 |
| 盤中即時量 | 證交所行情站 `mis.twse.com.tw getStockInfo.jsp`（上市 tse_ / 上櫃 otc_ 前綴） |

## 本機模式安裝與執行

```bash
pip install -r requirements.txt
python app.py
```

電腦瀏覽器開 <http://localhost:5000>；手機與電腦連同一 Wi-Fi 時，開 `http://<電腦IP>:5000`。

* **立即篩選** — 手動觸發（背景執行，完成後自動更新表格）。
* 系統每交易日 **15:30**（台北時間，盤後資料公布後）自動執行篩選。
* 盤中 09:00–13:30 每 10 分鐘自動檢查量能；也可按「檢查量能」手動測試。

所有門檻與時間都在 [`screener/config.py`](screener/config.py) 調整。

## 專案結構

```
stock-screener-tool/
├── app.py                     # 本機模式：Flask 伺服器 + APScheduler 排程
├── run_screen.py              # CLI：執行一次每日篩選（Actions/cron 用）
├── run_monitor.py             # CLI：執行一次量能檢查（Actions/cron 用）
├── run_finscan.py             # CLI：全市場財報掃描（每週，建立④判斷資料庫）
├── run_diagnose.py            # CLI：個股五條件診斷
├── .github/workflows/
│   ├── daily-screen.yml       # 雲端模式：每日 15:30 自動篩選
│   └── intraday-monitor.yml   # 雲端模式：盤中每 10 分鐘量能監控
├── screener/
│   ├── config.py              # 所有條件門檻與設定
│   ├── datasources.py         # 證交所 / 集保 / MOPS 資料抓取（含快取）
│   ├── screener.py            # 每日五條件篩選邏輯
│   └── monitor.py             # 量能監控（狀態存檔，跨執行接續計算）
├── docs/                      # 前端 PWA（GitHub Pages 與 Flask 共用）
│   ├── index.html             # 響應式儀表板：手機卡片 / 電腦表格
│   ├── manifest.json / sw.js  # PWA 安裝與離線殼快取
│   ├── icon-192.png / icon-512.png
│   └── data/                  # 篩選結果、警示、監控狀態（JSON）
└── requirements.txt
```

## 注意事項與限制

* 條件組合仍偏嚴格，多數交易日可能沒有
  或只有極少數股票符合，屬正常現象；可在 `config.py` 放寬倍數觀察。
* 「獲利能力大於 1.5」預設解讀為 **EPS > 1.5 元**；若您指的是其他指標
  （如營益率、ROE），請調整 `profitability_metric` 相關邏輯。
* MOPS 有流量限制，程式已內建查詢間隔與 7 天快取；大量重跑仍可能被暫時封鎖。
* 官方 API 欄位若有異動，`datasources.py` 以欄位名稱模糊比對，仍建議留意 log 警告。
* 本工具僅供研究參考，不構成投資建議。
